一个免费的浏览器端 [electerm](https://electerm.org) 终端主题编辑器。用实时预览设计自己的配色方案，保存到云端并与社区分享，或浏览、改编其他人创建的主题。

![electerm 主题编辑器截图](./src/docs/screenshot.jpg)

## 功能特性

- 🎨 **可视化主题编辑器** — 颜色选择器与文本编辑器，配合 electerm 演示站点驱动的实时预览
- ☁️ **云端保存与分享** — 使用 GitHub 登录即可保存主题并发布到公共广场（每个账户最多 10 个）
- 🖼️ **主题广场** — 浏览社区主题，带颜色预览卡片和作者信息，可按最新或最热排序
- ❤️ **点赞、复制与分享** — 点赞主题、复制配置到剪贴板、在编辑器中编辑，或分享到社交媒体
- 🌍 **双语支持** — English 与 简体中文，支持客户端语言切换
